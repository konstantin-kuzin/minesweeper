# Minesweeper

Классический «Сапёр» в браузере с нелепым пиксельным персонажем, звуками и тремя режимами сложности.

Стек: чистый HTML, CSS и JavaScript, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере.


## Управление

| Действие | Как |
|----------|-----|
| Открыть клетку | Левый клик |
| Поставить / снять флаг | Правый клик |
| Новая игра | Кнопка со смайликом в панели — снова откроется выбор режима |

При первом открытии клетки расставляются мины (кроме режима «Дева» — там поле фиксированное). Запускается обратный отсчёт **2:30** (150 секунд); при ≤30 секунд таймер подсвечивается.

## Режимы

При старте появляется диалог с вопросом про гороскоп — от него зависит режим:

| Режим | Поле | Мины | Особенности |
|-------|------|------|-------------|
| **Обычный** | 10×10 | 10 | Классические правила; после хода поле может случайно повернуться на 90°, −90° или 180° |
| **Рыбы** | 7×7 | 10 | Цифры на открытых клетках скрыты; при попадании на мину она переносится в другое место вместо взрыва;|
| **Дева** | 10×10 | 20 | Мины в двух нижних рядах;|



## Механики

- **Первый клик безопасен** (в обычном и «Рыбах»): мины не ставятся в зоне 3×3 вокруг первой открытой клетки.
- **Автораскрытие** пустых областей (flood fill), как в классическом сапёре.
- **Поворот поля** (кроме «Рыб»): после открытия клетки или установки флага с заданной вероятностью поле поворачивается; цифры на клетках анимированно «выравниваются». Костя комментирует поворот фразой из облачка.
- **Счётчик мин** и **таймер** в стиле Windows Minesweeper.
- **Звук** через Web Audio API (открытие, поворот, «победа»/«поражение»).
- **Костя** — пиксельный персонаж слева от поля: бродит по дорожке, реагирует на поворот, победу и поражение (GIF-анимации).
- **Конфетти** при «победе» в игровой логике (см. ниже).

> Игра намеренно переворачивает ожидания: при взрыве мины звучит «победная» мелодия и смайлик 😎, а при очистке поля — взрыв и 😵. Сообщения `GAME OVER` и `YOU WIN!` тоже расставлены с иронией — это часть задумки, а не баг.

## Требования

Современный браузер с поддержкой ES6+, CSS Grid и Web Audio API. Для звука после загрузки страницы может понадобиться любое действие пользователя (клик) — ограничение браузеров на автозапуск аудио.
